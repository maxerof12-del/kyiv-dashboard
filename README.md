# Kyiv Dashboard

Android-дашборд для старого телефону (горизонтально, 1280×800):

- годинник, дата, погода (Open-Meteo), заряд батареї, свята й пам'ятні дні
- повітряна тривога (м. Київ / Київська область)
- індивідуальний графік світла ДТЕК Київські електромережі за адресою — сьогодні й завтра, «вимкнуть/увімкнуть о …»
- ліміти Claude (5 год / тиждень) і Codex (ChatGPT) із запасом відносно часу, що минув

## Встановлення

1. На телефоні відкрийте **Releases → latest** цього репозиторію й завантажте `KyivDashboard.apk`
   (або Actions → останній запуск → Artifacts).
2. Дозвольте встановлення з браузера, встановіть.
3. Торкніться «⚙ налаштування»: увійдіть у Claude та ChatGPT, перевірте адресу.

Кожен push у `main` автоматично збирає новий APK; він ставиться поверх старого.
